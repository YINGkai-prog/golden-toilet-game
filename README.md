# 金盒公司 / NIGHT SHIFT

50 人即時辦公室共創遊戲。Release `nightshift-2026.10.05`（2.2.0）。

## 開始

執行 `node server.js`；雲端設定 `HOST_KEY`，使用 `/host?key=你的金鑰` 開啟主持台。玩家使用 `/`。主持人開放報到後，倒數三秒即可加入。

## 一個人測試

主持台的「補滿玩家至 50 人」會自動開放報到，扣除現有真人、測試同仁及報到中的名額再補人。連按不會重複灌入。測試同仁使用正常選舉、移動、施工、遊戲室、海報和投票規則；主持人仍需切換階段。需要親自操作時，先開放報到，在「自己加入測試」加入角色，再補滿玩家。若你是第一位董事，兩位測試董事會投票給你。清除測試同仁會保留真人，並移除測試作品；董事群變動時重新選舉。

## 夜間森林與加班別墅

夜間森林中的原創設計別墅，暗色介面與室內暖光，包含 60 個完整工作席（研發各 24、行銷 12）、咖啡吧、遊戲室、董事會、廁所及獨立 AI 機房。戶外有中庭足球場、林蔭花園、露台、吸菸區、斑馬線與園區馬路、森林步道；背景城市與森林延伸至霧化地平線。可行走的是別墅及園區範圍，遠景為景觀。

滑鼠點擊目的地，拖曳旋轉，右鍵或 Shift＋拖曳平移，滾輪或雙指縮放。「全景／園區／近看／跟隨角色」提供鏡頭捷徑。房間選單同時聚焦空間。家具、牆面與伺服器尋路共用布局，角色繞障礙行走；50 人的身體零件以批次繪製降低渲染負擔。

## 個人分身、娛樂與投影

報到前可重新隨機產生三款造型，再選擇三種配色之一。伺服器分配不同的造型組合及色碼，真人與測試同仁都不撞款。玩家姓名與職稱使用帶引線的浮動吊牌；主管、處長、董事與董事長有金色光環。

中庭足球以角色碰撞觸發高速踢球，邊界反彈、左右進球與回中圈由伺服器同步。飛鏢使用移動準星，30 秒最多十鏢，按鈕或空白鍵投擲。彈珠台有三顆球、45 秒一局，左右鍵或畫面擋板按鈕操作，球與得分由伺服器模擬。離開遊戲室即中止。

茶水間的咖啡賽共用三秒準備及 30 秒倒數，依序研磨、萃取、出杯，杯數最多者獲勝、同杯數並列。操作有製作時間，不能直接提交分數；離開茶水間該輪退賽。結果保留至少八秒。可切換跳舞動作。

「作品直播」同時展示 A、B、C 三隊積木、即時指導、海報與辦公室實況。主持人可開啟 `/screen` 投影專頁，使用公開唯讀連線，不需要主持金鑰；可切回辦公室實況。主管原有幽默指導貼紙、處長改方向、董事長巡視仍保留。

半透明機房內含以 GB300 機櫃為視覺參考的模型與閃爍狀態燈，所有人看得到，只有董事長能走進去。這是遊戲美術及 AI 活動示意，不代表實際部署在 GB300 硬體。

## 規則

- 最快報到的三人成為董事。只能投給另外兩位董事；取得兩票立即當選，不必等第三票。三人各一票，清空票數、進入下一輪。董事長未選出前不能開案。
- 其餘玩家分配研發一處、研發二處及行銷處。兩支研發隊與自主 AI 的 C 隊競賽。董事長選擇題目、上市產品及官方海報。
- 點擊場景房間或下方空間選單移動。拖曳旋轉、滾輪／雙指縮放；可跟隨自己的角色。路線及角色位置由伺服器計算。
- 必須在自己的研發區才能放置或拆除積木；離開時停止施工並累計離崗時間。茶水間可跳舞或參加 30 秒咖啡賽；遊戲室有飛鏢、彈珠台及原有 20 秒光點反應／記憶迴路挑戰。
- AI 隊使用內建自主策略引擎，依題目調整產品、根據兩隊進度加速、持續建造並優化。無外部模型／API 依賴。機房只有董事長可進入與查看策略，伺服器驗證門禁。
- 主持台依序推進董事選舉、開案、共創、評選、上市推廣、海報評選及發表會。評選包含 A／B／C 三隊；行銷提交海報，其餘玩家填寫市調。成果可下載 ZIP。

## 驗證

`npm test`（測試需要 Node 22+ 的 WebSocket）。涵蓋 50 條真實連線、重連、禁止自投、平票重投、門禁、移動、施工權限、遊戲室計分、AI 建造／暫停、C 隊上市、海報、市調及成果匯出。

`tests/villa.test.cjs` 另驗證主持權限、補滿佇列、重複按鈕、保留真人、測試董事選舉、全機器人完整流程、家具碰撞與戶外路徑。

`node tests/visual.cjs` 使用 Playwright；Windows 使用已安裝的 Edge，其他平台使用 Playwright Chromium。請在允許瀏覽器 IPC 的測試環境執行，不要停用系統核准或安全措施。畫面測試涵蓋桌機、手機、畫布實際放置、鏡頭、遊戲室與海報提交。

`node tests/villa-visual.cjs` 實際點擊補滿／清除／加入角色按鈕，檢查 50 人、森林別墅、花園、吸菸區、道路、森林導航、右鍵平移與手機版。

伺服器不需 npm 相依套件。場景使用專案內的 Three.js。WebSocket 中斷時會重連，並保留 HTTP 輪詢備援。

## 儲存與部署

`data/` 保存本機狀態；雲端未掛持久磁碟時重啟不保證保存進度。2.0 使用 schemaVersion 2，舊 1.x 活動狀態不相容，首次升級會建立新場次。部署應在活動尚未開始時進行。`GET /api/info` 可驗證版本。

2.1 保留 2.0 遊戲資料格式；舊布局的角色位置會移到新別墅大廳，已保存的測試同仁可在服務重啟後繼續活動。`/api/info` 額外回報布局版本及工作席數。



2.2 保留既有遊戲資料格式，舊位置移回大廳並補上唯一造型。新增 `tests/nightshift.test.cjs` 驗證造型、防造假計分、30 秒競賽／平手／退賽、足球碰撞與擋板物理；`tests/nightshift-visual.cjs` 驗證真人造型選擇、50 人吊牌、各娛樂實際操作、右鍵方向、手機排版及投影同步。
